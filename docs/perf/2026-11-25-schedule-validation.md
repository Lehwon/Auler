# 배치 평가와 전체 충돌 검사 측정

Windows 11 Pro 10.0.26300, Intel Core Ultra 7 255H, Rust 1.100.0에서 릴리스 빌드로 측정했다.

```powershell
cargo run --release -p auler-engine --example validate --locked
```

기존 잠금 배치는 유지했다. 나머지 배치 단위에는 고정된 순서로 요일·교시·강의실을 지정했다. 충돌이 포함된 편성 초안에서 강의실 후보 전체와 전체 편성 검사를 각각 300회 실행했다. 데이터 읽기와 평가기 인덱스 생성은 측정 구간 밖에서 했다.

| 가상 데이터 | 분반 / 배치 단위 / 강의실 | 측정 | 중앙값 | p95 | 최대 |
|---|---|---|---:|---:|---:|
| 기준 학과 | 42 / 68 / 12 | 강의실 후보 전체 | 0.016ms | 0.018ms | 0.027ms |
| 기준 학과 | 42 / 68 / 12 | 전체 충돌 검사 | 0.105ms | 0.136ms | 0.303ms |
| 스트레스 | 150 / 222 / 30 | 강의실 후보 전체 | 0.086ms | 0.183ms | 0.288ms |
| 스트레스 | 150 / 222 / 30 | 전체 충돌 검사 | 0.757ms | 1.085ms | 1.748ms |
